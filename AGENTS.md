# Development rules

- This project has not been deployed. Change the single current wire, storage, and API formats directly; do not add version negotiation, upgrade paths, or backward-compatibility code unless explicitly requested.
- Never renumber existing numbered items or identifiers in any file. Deletions leave gaps, and additions use previously unused identifiers. This applies to requirements, design sections, protocol and schema fields, error codes, test identifiers, and every other numbered sequence.
